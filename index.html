편한 PDF 리더

휴대폰에서 크게, 편하게, 이어서

iPhone: Safari 아래쪽 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.

최근 본 파일

    아직 연 파일이 없어요. 위 버튼으로 PDF를 열면 여기에 저장되고, 다음부터는 한 번 눌러 읽던 곳부터 이어서 볼 수 있어요.

    사용법
    • 두 손가락으로 벌리면 확대, 오므리면 축소
    • 두 번 톡톡 치면 2배 확대, 다시 두 번 치면 원래대로
    • 화면 왼쪽·오른쪽 끝을 톡 치면 한 화면씩 위·아래로 넘어가요
    • 가운데를 톡 치면 위·아래 메뉴가 숨거나 나타나요
    • 아래 "12 / 300" 숫자를 누르면 원하는 쪽으로 바로 이동
    • 메뉴(≡): 여백 자르기, 야간·세피아 화면, 글자 모드(글씨만 크게), 책갈피, 목차
    • 다시 열면 마지막으로 읽던 곳에서 이어서 열려요
    • 파일은 이 휴대폰 안에만 저장돼요. 어디에도 올라가지 않아요.
